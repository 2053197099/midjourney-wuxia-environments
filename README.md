# 东方武侠游戏场景 Midjourney Skill

这是一个用于创作**东方武侠与神话游戏纯场景画面**的 Codex Skill。它把用户给出的主题转成一组可以直接交给 Midjourney 的中英文提示词：从主题联想到同一世界里值得探索的地点，再为每个地点选择合适的镜头、构图、氛围和光影。

目标不是堆叠古风符号或生成宏大的概念壁纸，而是让一个真实可信、空间关系清楚的场景，因为摄影机位置和画面组织而令人印象深刻。室内的一张桌子、街边的摊位、一段崖壁木桥，都可以成为画面主体。

## 适用范围

- 东方武侠、历史奇幻与东方神话游戏的环境场景。
- 用户提供一个主题，希望联想到同一世界中功能、地理、生活或交通相关的其他地点。
- 为已有场景设计更有辨识度的取景、构图、光线和氛围。
- 用户明确要求时，分析游戏场景参考并提炼可迁移的视觉方法。

本 Skill 只负责**场景提示词**，不用于角色立绘、人物设定或剧情编写，也不会自动生成图片。

## 使用方法

在 Codex 对话中调用 `$midjourney-wuxia-environments`，然后说明主题、数量和必要限制。主题明确时，默认从它出发做合理的跳脱联想；不需要先确认是否扩展，也不编造一段世界观故事。

```text
使用 $midjourney-wuxia-environments，宗门，给我 8 组场景提示词。
```

```text
使用 $midjourney-wuxia-environments，街道，给我 6 组场景；联想到酒楼、客栈、摊贩或刀匠铺等街区生活空间。
```

```text
使用 $midjourney-wuxia-environments，给我 5 组雪地场景，避免宏大远景，多用近景和中景。
```

如果没有提供可执行的主题，也没有说“随机”“由你选”或“不限主题”，Skill 会先问一个简短问题，等主题明确后再生成。用户明确授权随机选题时，则直接开始。

## 默认生成规则

- **数量**：每批默认 5–10 组；用户指定数量时按指定数量生成。
- **联想方式**：以用户主题为起点，扩展到同一世界内合理相关的地点。关联可以来自地理、日常生活、营生或通行功能；每个场景不必重复主题中的标志物。
- **纯场景**：默认无人、无 NPC、无角色剪影。用建筑、门窗、道路、桥梁、树木或地形体现空间尺度。
- **画面信息**：每条提示词围绕一个明确主体，只保留必要环境锚点；不确定的设施或空间关系宁可删去，也不臆造补全。
- **空间可信**：室内、室外或过渡空间按场景自然表达，不使用固定前缀。建筑结构保持简单可信；画面层次主要由前中后景、遮挡、光影和框景建立。
- **镜头与画面**：根据场景变化选择景别、机位和观看路径，不默认平视、正面、中轴对称或完整展示建筑。
- **氛围与光影**：明确视觉焦点及亮暗关系，让光线参与构图，不让整个画面平均发亮。
- **东方意境**：通过藏露、虚实、疏密、远近、动静、明暗和留白建立；不靠古风物件或符号堆叠。
- **环境叙事**：通过空间状态、时间天气、使用痕迹和自然侵蚀形成联想，不用套路道具解释剧情。

## 输出格式

每组包含场景名和中英文提示词。场景名放在代码块外；所有中文提示词合并在一个代码块，所有英文提示词合并在另一个代码块；代码块中只放可复制的提示词。

每条提示词包含以下画面要素，但会按场景自然组织，不机械拼装固定模板：

> 主体 + 场景 + 镜头 + 构图 + 氛围 + 光影 + 必要限制词

镜头、构图、氛围和光影是必需的；无助于识别主体、组织画面或建立氛围的形容词和陈设会删去。Skill 不会为了显得“游戏 CG”而机械添加 `epic`、`AAA`、`monumental` 等标签。

## 项目文件

```text
.
├── SKILL.md                         # 生成流程、画面规则与输出自检
├── agents/openai.yaml               # Skill 展示信息和默认调用说明
└── references/
    ├── game-reference-study.md      # 游戏场景参考分析
    ├── scene-library.md             # 可按需查阅的场景灵感
    └── visual-system.md             # 镜头与画面设计参考
```

参考资料只在用户明确要求分析参考、扩展场景灵感或研究镜头画面时按需读取；常规生成不需要先查资料。

## 自检

输出前会逐条检查：场景是否符合主题；物件是否属于该地点且用途合理；空间连接和摄影机位置是否成立；镜头、构图、氛围与光影是否互相配合；是否无人；是否存在不必要或不确定的细节。发现问题就删改提示词，不用额外道具或剧情填空。

## 安装

将仓库放入 Codex 的个人 Skills 目录，然后在新对话中调用：

```bash
git clone https://github.com/2053197099/midjourney-wuxia-environments.git ~/.codex/skills/midjourney-wuxia-environments
```

如果仓库设为私有，先确保当前 Git 环境已登录有权限的 GitHub 账号。安装路径已有同名目录时，不要覆盖；先备份或选择合适的 Skills 目录，再安装。
