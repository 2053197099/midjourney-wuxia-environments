# 东方题材游戏场景 · Midjourney Skill

把东方题材、地点名称、场景清单或已有设定，转成可复制到 Midjourney 的**中英文纯环境提示词**。适合游戏场景概念设计，从整片地貌、村落与建筑群，到庭院、室内、建筑构件和材质局部都可生成。

- **调用名称**：`$midjourney-wuxia-environments`
- **默认输出**：10 组；明确指定数量时按指定数量。
- **核心原则**：一个环境主体，加上其周围应有的场景细节。
- **职责边界**：生成文本提示词，不自动生成图片、制作3D模型、设计角色或编写剧情。

调用名保留了最初的 `wuxia` 标识，实际范围已覆盖 28 类东方题材，并不限于武侠。

## 能做什么

| 功能 | 使用方式与结果 |
|---|---|
| 按主题生成 | 给出“江南园林”“西域荒漠”“聊斋志怪”等方向，生成同题材下不同地点的提示词 |
| 按清单生成 | 提供场景名称列表，保留名称与功能，逐项设计具体画面 |
| 整理已有设定 | 将空间、材质、光影与异常设定转成可见画面，不确定的细节不臆造补全 |
| 调整取景 | 按要求使用全景、远景、中景、近景或特写，控制机位、裁切与背景范围 |
| 使用视觉参考 | 将作品或已看到的参考图转化为空间、材质、色彩和光影描述，默认不把参考作品名写进成稿 |
| 中英文对应 | 中文先成稿，英文保持相同场景顺序、物件、空间、镜头与光线 |

题材包括历史生活、武侠江湖、暗黑武侠、仙侠、神话、聊斋志怪、民俗恐怖、三国战争、敦煌、水墨、东方废土、赛博东方与机关术等。完整 28 类目录与环境落点见[题材映射](references/oriental-genre-map.md)。只给具体地点也可以，不必先选目录分类。

## 安装与调用

这是 **Codex Skill**。先安装到 Codex 能发现的 Skills 目录，再在支持 Skills 的对话中调用；它不是直接导入 Midjourney 的插件。

以个人 Skills 目录为例：

```bash
git clone https://github.com/2053197099/midjourney-wuxia-environments.git ~/.codex/skills/midjourney-wuxia-environments
```

已有同名目录时先检查，不直接覆盖。私有仓库需要有读取权限。安装后在新对话中输入：

```text
使用 $midjourney-wuxia-environments，江南园林，生成10组中英文场景提示词。
```

**最少只需提供一个主题或地点。** 数量、景别、风格、光影和限制都可选填。主题明确、承接上一主题或要求随机时直接生成；主题不明时只确认一次方向，不追加子类问卷。

## 常用指令示例

### 主题生成

```text
使用 $midjourney-wuxia-environments，西域村落与遗址，生成10组。荒漠沙地为主体，使用宽阔全景，建筑作为环境中的少量锚点。
```

### 按场景清单生成

```text
使用 $midjourney-wuxia-environments，按以下清单生成3组东方志怪CG场景：
剥画古寺
墨染山溪
空面归画廊
```

### 指定近景与特写

```text
使用 $midjourney-wuxia-environments，古寺，生成6组：3组建筑局部近景、3组材质特写。保留与寺院的空间关联，不展示完整殿堂。
```

### 给出作品或图像参考

```text
使用 $midjourney-wuxia-environments，聊斋园林，生成10组。参考《倩女幽魂》的幽冷气质，把参考转成具体画面，不在提示词里写作品名。
```

图像参考需要附在当前对话中；没有看到的图片不会被当作已分析。只要求生成时直接出提示词，明确要求研究参考时才提供对应分析。

### 指定风格与生物限制

```text
使用 $midjourney-wuxia-environments，山林废寺，生成10组。使用Unreal Engine 5拟真渲染与电影级体积光，可有少量远处飞鸟，环境始终是主体。
```

```text
使用 $midjourney-wuxia-environments，雨夜水乡，生成5组。完全不出现人物、动物或其他活动生物。
```

## 默认画面规则

- **环境主体集中**：主体可以是地貌、建筑群、单体建筑、设施或局部构件；周围细节交代位置、用途、连接与状态，不并列制造多个竞争主体。
- **场景始终是主体**：默认无人，不以活体动物、异兽或妖怪承担主角。少量鸟类、蝴蝶等可按栖境陪衬，不抢占画幅、篇幅、光照或构图落点；静态石像、纸扎等环境造物可保留。
- **生物相关名称转为环境**：“异兽涉行的浅滩”通过足迹、墨痕或扰动水纹表达；“绢蝶栖息的枫林”保留林地与少量绢蝶，不改成蝶翼肖像。
- **景别有变化**：未限定时，默认十组至少两组真正近景和一组特写，其余按内容安排；用户指定全景、比例或完整展示时优先服从，不为配额改变范围。
- **描述符合取景**：大场景先写地形、群体布局与通路，避免小道具抢走整体；近景围绕主体及邻近环境，不扩写镜头外的全街或全屋。近景与特写不以活体生物为主体。
- **空间和光影可信**：设施符合用途，连接可读，交代光源、受光面与暗部，不平均照亮，不机械加雾、雨或宏大叙事。幻想可以超现实，但异常关系须清楚。
- **题材与风格按需选择**：不擅自混搭题材，不固定追加某种渲染器或品质标签。赛博和机关场景保留必要技术设施，限制词不能否定主体。
- **一次自检**：检查主体、空间、景别、光影、生物陪衬、参考转化、双语及批次差异，只修问题部分，不确定的细节删除。

默认限制词为**无人、无可读文字、无水印**。允许鸟蝶陪衬时不会同时写“无动物”；明确要求完全无生物时遵从。

## 提示词结构与输出格式

每条提示词自然组织成一段，包含：

> 主体 + 场景 + 镜头 + 构图 + 氛围 + 光影 + 必要限制词

| 环节 | 具体要求 |
|---|---|
| 主体 | 一个环境主体，先写清形态与状态 |
| 场景 | 补充主体周围应有的细节，服务位置、用途与空间连接 |
| 镜头 | 明确景别、机位、视角或裁切，描述范围与镜头一致 |
| 构图 | 选择偏心、纵深、对角线、遮挡或留白等主要关系 |
| 氛围 | 用时间、天气、材质与空间状态支撑，不只堆抽象形容词 |
| 光影 | 写清光源方向、受光与暗部，按景别控制细节 |
| 限制词 | 保留必要限制，避免与主体、技术设施或陪衬生物冲突 |

这不是固定顺序的填空模板。主次由描述顺序、篇幅、光影与背景取舍体现，不把“唯一视觉中心”“主读点”等内部判断写进成稿。

每批按以下顺序输出：

1. 在代码块外列出编号与场景名称。
2. 一个合并代码块放全部中文提示词，条目之间空行分隔。
3. 另一个合并代码块放全部英文提示词，顺序与中文一致。
4. 末尾一句实际自检结论。

代码块中只有提示词，不放编号、名称或解释。默认不附大段世界观、分析、机位表或计时报告。把所需英文条目复制到 Midjourney 使用即可；也可使用中文版本。
