# 东方武侠游戏场景 Midjourney Skill

面向东方武侠与神话游戏的纯场景 Midjourney 提示词 Skill。重点是从主场景跳脱联想到同一世界里功能或生活相关的地点，再为每个地点设计镜头、构图、氛围与光影；不默认编写背景故事或人物剧情。

## 内容

- `SKILL.md`：生成流程、场景与摄影规则、输出自检。
- `agents/openai.yaml`：Skill 展示信息与默认调用说明。
- `references/`：按需使用的游戏场景参考分析、场景灵感库与摄影选择资料。

## 默认输出

- 纯场景、无人；每次 5–10 组，用户指定数量优先。
- 提示词提供中文与英文版本；场景名置于代码块外，两种语言各自合并在一个只含提示词的代码块中。
- 主题明确时，以主题为联想起点，默认跳脱联想到同一世界里合理相关的地点；仅主题不明确时追问。
