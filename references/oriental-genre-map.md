# 东方题材场景映射

这份速查表把题材气质转成可画的环境。它不是场景清单，也不是要求在一张图里塞满该题材的所有元素：每次只选符合用户主题的地点和少数环境锚点，继续按场景自身设计镜头、构图、氛围与光影。

## 完整题材目录

保留用户原有 26 类，补充暗黑武侠与三国／古代战争，共 28 类。以下分组方便查找，不意味着自动混搭；每种题材均可直接输入，选定后进入同一套生成流程。水墨、敦煌等也可作为明确指定的视觉方向。

## 环境表达

默认生成纯环境画面，不出现人物，不以活体生物为主体。鸟类、蝴蝶等可按栖境少量陪衬，环境仍承担主要画幅与描述，近景和特写不转为生物肖像。异兽、妖怪、神祇、仙人和仪式等内容，转成栖居地、遗址、神像、祭场、建筑状态、自然现象或使用痕迹，场景名称中的生物不自动作为画面主角。历史生活题材保持日常功能可信；神话、梦境、东方幻想和异文明可超现实或巨构，但空间关系仍须读得清。只有用户明确指定混合题材时才融合不同类型，不自动把它们都混成“古建、山雾、灯笼”。

| 题材方向 | 可落到环境中的地点与锚点 | 主要视觉组织 |
|---|---|---|
| **山海经／上古异兽** | 神山、部落遗址、荒祭坛、异兽栖域与地貌痕迹 | 原始粗粝、巨物尺度、蛮荒自然；异兽可由巢穴、遗骨或地形痕迹暗示 |
| **古风修仙／仙侠** | 仙门、御剑台、洞府、渡劫地、云海路径 | 垂直、轻盈、超现实；以浮空、天象或灵性光场建立仙气，不强制宫殿群 |
| **聊斋／中式志怪** | 荒宅、空置鬼市、古寺、纸窗院落、画中空间 | 日常空间轻微错位；幽暗与艳色并置，留出未解释的空处 |
| **东方玄幻** | 浮空城、灵脉节点、法阵遗址、巨型宗门、秘境入口 | 宏大尺度与局部空间并存；选一条清楚的奇异规则作为视觉中心 |
| **武侠／江湖** | 客栈、竹林、古镇、镖局、山门、雪夜驿路 | 苍凉或烟火气由真实用途、风雨材质和行路空间建立，不默认加入法术奇观 |
| **暗黑武侠** | 破败关城、地下武库、旧宅、禁闭院落、险峻通路 | 危险感来自逼仄与开放空间的对照、材质磨损及局部强光；暗黑不等于全画面漆黑，不自动加入怪物或机械 |
| **西游神话** | 天宫、妖国、龙宫、地府、火焰山及其关隘 | 神魔奇幻与地域特征结合；单图聚焦一处，不把整部神话场景拼成合集 |
| **封神／商周神话** | 青铜祭坛、古战场、祭祀台、法器库、王城遗迹 | 青铜、礼制与神性秩序；以器物尺度和空间仪式感表现，不依赖神将出镜 |
| **中式克苏鲁／东方诡秘** | 深山禁地、邪祀遗址、封闭石室、无法辨认的古代结构 | 未知、巨物压迫、局部失序；用尺度和空间异常暗示，不直白展示怪物 |
| **民俗恐怖／中式怪谈** | 空置戏台、祠堂、送葬古道、冥婚院落、纸扎作坊 | 地方禁忌与熟悉空间发生冲突；红白物件少量出现，保持空场和克制 |
| **中式妖怪／百妖夜行** | 妖市街巷、废弃摊棚、精怪栖所、异常足迹与门窗 | 市井秩序被轻微改写；通过尺寸、开合和使用痕迹暗示非人活动，不堆百种怪物 |
| **地府／阴曹世界** | 黄泉路、奈何桥、鬼门关、酆都街巷、忘川渡口 | 阴森且有制度秩序；水路、城门和重复尺度组织东方死亡美学 |
| **敦煌／飞天仙境** | 沙漠石窟、壁画殿、佛国廊道、被风沙掩埋的神殿 | 矿物色、石壁和流动线纹；以壁画残色、飘带纹样与空间留白表现轻盈，不需画出飞天人物 |
| **佛教神话／东方神性** | 巨佛石窟、佛殿、塔内石室、护法神像、佛国入口 | 庄严、静穆、巨构；以尺度差、暗部和局部神光形成中心，不默认多层宫殿 |
| **道教神话／道法世界** | 山间道观、炼丹室、符阵庭院、洞天入口、雷法祭台 | 山势、方位和仪式结构结合；让阵法或天象依附于空间，不散落符箓当装饰 |
| **古蜀／三星堆幻想** | 青铜神树殿、黄金面具祭场、地下神殿、古蜀遗址 | 青铜、金色和异文明几何；以少量高辨识度构件建立陌生感 |
| **苗疆／巫蛊幻想** | 山寨吊脚楼、密林祭台、虫瓮作坊、藤桥与雨林水路 | 潮湿、幽深、有机；从聚落结构和自然环境落笔，避免把地域文化简化成猎奇符号 |
| **傩文化／原始祭祀** | 傩面库房、古村祭场、火塘、夜祭通道、戏仪台口 | 面具、火焰与空场形成仪式张力；控制色彩和道具数量，不依赖人群 |
| **水墨仙境** | 云海山径、孤舟水岸、巨峰、空山亭、消失的渡口 | 留白、远近虚实和少量墨色；建筑与物件只在需要时出现 |
| **宋韵／东方生活美学** | 茶楼、庭院、江南水巷、夜市、园林、书斋 | 雅致克制、尺度亲近；以日常用途、材质和疏密关系建立生活气息 |
| **盛唐幻想** | 长安街巷、灯会、胡商市集、宫苑、夜宴空间 | 繁华、浓艳、开放的城市尺度；市场与街道同样重要，不把所有画面变成宫殿 |
| **三国／古代战争** | 城关、军营、粮仓、军械库、渡河营垒、战争遗址 | 防守、补给与地形决定空间；用城墙、空置设施和受损状态表达战争背景，保持无人，不靠堆盔甲或兵器说明剧情 |
| **东方废土** | 废弃寺庙、巨佛残构、荒城、断壁、被沙土吞没的街道 | 古文明遗存与毁灭后的自然侵占并置；用材质和空间空缺表达，不自动覆满浓雾 |
| **赛博东方／赛博武侠** | 霓虹古城、未来长安、数字符阵街区、机械化水巷 | 古典空间与未来技术发生清楚对照；画环境和基础设施，不转成人物或武器设计 |
| **东方蒸汽朋克** | 木构机械城、铜铁管路、齿轮枢纽、蒸汽工坊 | 古代材料与可读的动力结构结合；只设一处主要机械焦点，避免齿轮堆满画面 |
| **东方机关术／墨家幻想** | 机关城、木牛流马工坊、机关兽仓、地下水利设施 | 精密结构、传动路径和功能关系清楚；机械必须像能运转的空间设施，而非随机零件 |
| **东方海洋神话** | 龙宫、海底神殿、鲛人旧城、沉没古城、潮汐闸门 | 深海压迫、折射光和水下尺度；用水体、珊瑚、沉积物说明空间，不需要生物出镜 |
| **东方梦境／诗词幻想** | 月宫、桃花源、梦中长安、诗意山水、时间错位的庭院 | 情绪和空间转换为主；用尺度、天气、路径和局部异象具象化，不把诗句逐字堆成物件 |

若用户只给地域或地点而未指定上述题材，不要擅自选一种幻想类型；按地点功能和用户的具体描述生成。若用户给出题材与场景（如“宋韵江南茶楼”），以场景用途为主体，题材只负责材质、空间和氛围的定向。
